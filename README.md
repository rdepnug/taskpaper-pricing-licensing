## TaskPaper 到底怎么用：一个渲染纯文本的编辑器

理解 TaskPaper 最快的方式，是别把它当待办 App，把它当一个文本文件的阅读器。

你的清单本身就是一个 `.taskpaper` 纯文本文件。以冒号结尾的行是项目，以短横线开头的行是任务，`@due`、`@done` 这样的词是标签。你在里面打字，格式实时生效，不需要设置任何东西。

软件做的事情是把这份文本渲染得好看，然后给你几个键盘操作：折叠暂时不看的段落，聚焦到某一个项目，用查询语句过滤。比如输入 `@due and not @done`，屏幕上就只剩下有截止日期且还没完成的任务。样式表可以自定义，也能写脚本批处理。

这个设计的好处是文件永远属于你。用 TextEdit 打开能读，用 vim 打开能改，二十年后随便找个文本编辑器都还在。同步不靠它，你把文件放在 iCloud Drive 或者 Dropbox 里，剩下的交给系统。坏处也同样明显，后面会讲。

真正的门槛在查询语法和样式表这一层。上手第一步很容易，打字就行；想把过滤规则用顺手，得花点时间读文档。这也是它评价分化的重要原因，有人觉得清爽，有人觉得折腾。

## 买之前必须知道的几个限制

**只支持 macOS 11 或更高版本，没有 iOS、Windows 和网页版。** 官方没有出 iPhone 应用。想在手机上用，只能用 Editorial、Taskmator 这类第三方编辑器打开 `.taskpaper` 文件，体验和桌面端不是一回事。

**没有提醒，没有日历，没有通知。** 这一点开发者自己在使用指南里就承认，手机端的快速收集和提醒是弱项，建议搭配 Apple Reminders 一起用。也就是说，你如果指望它到点弹窗提醒你开会，它做不到。

**没有第一方同步，也没有冲突解决。** 文件放在哪个网盘，同步就是那个网盘的能力。两台 Mac 同时改同一个文件，合并逻辑由网盘决定，TaskPaper 不介入。多人协作就更不用想了。

**开发处于维护状态。** 2025 年 11 月发布的 3.9.4 版本修的是 macOS 26.1 上的崩溃问题，不是新功能。开发者对它的定位是“完成品”，功能层面不会再有大的扩展。这对喜欢稳定的人是好事，对期待新功能的人是坏消息。

**没有免费版。** 官网直接下载版提供 1 周试用，不需要绑卡；Mac App Store 版没有试用。想先试试手感的，从直接下载版开始更合理。

**退款要按渠道走。** Mac App Store 上买的数字商品，退款申请提交给 Apple，不走开发者。国内渠道购买的话，退款条件看页面条款，下单前自己确认一遍。

## 谁该买，谁应该直接关掉页面

**适合买的人**：已经有纯文本或 Markdown 工作流的人；习惯全程键盘操作、讨厌鼠标点来点去的人；只用 Mac、不需要手机端实时同步的人；明确不想被订阅绑住、宁可一次付清的人。如果你现在用 Obsidian 或者一堆 txt 文件管事情，TaskPaper 提供的是一层更顺手的渲染和过滤，迁移成本几乎为零。

**不适合买的人**：需要到点提醒的人；需要在 iPhone 上随时记一笔的人；需要和别人共享清单的人；需要看板、甘特图、时间块这些视图的人；用 Windows 或 Linux 的人。这几类需求 TaskPaper 一个都满足不了，勉强买了最后还是会退回 Things 或者 OmniFocus。
